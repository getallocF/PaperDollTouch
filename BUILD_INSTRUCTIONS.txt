================================================================================
PANDUAN BUILD, PEMASANGAN & PENGGUNAAN — MINECRAFT MOBILE CURSOR (v2.0.0)
Target: LeviLauncher Android — Minecraft Bedrock 26.60 (arm64-v8a)
================================================================================

1. RINGKASAN FITUR UTAMA (v2.0.0)
--------------------------------------------------------------------------------
- Kursor Pointer Putih Standar Windows:
  Muncul HANYA ketika layar GUI terbuka (Player Inventory, Chest, Crafting Table,
  Furnace, Anvil, Villager Trading, Pause Menu, Settings) dan langsung hilang
  100% saat kembali ke gameplay normal (berjalan, berlari, bertarung, menambang).
- Green Slot Hover (#38E54D) Persis Minecraft Windows:
  Menampilkan outline hijau tajam pada slot aktif yang ditunjuk oleh kursor
  tanpa menutupi ikon item, jumlah stack, durability bar, atau tooltip.
- Kepala & Leher Player Mengikuti Kursor (PaperDoll Cursor-Follow):
  Saat GUI menampilkan model karakter (Paper Doll), kepala (yaw ±62°, pitch ±38°)
  dan badan (yaw ±26°) mengikuti posisi kursor secara halus tanpa mengubah arah
  kamera dunia atau mengirim paket jaringan.
- Menu In-Game "Mobile Cursor Settings":
  Dapat dibuka langsung dari tombol [Cursor] di pojok kanan atas saat GUI terbuka
  untuk memilih ukuran Small (0.75x), Medium (1.00x), Large (1.50x), atau menggeser
  slider 0.75x - 2.00x secara real-time tanpa restart game.

2. CARA BUILD CEPAT DI TERMUX & GITHUB ACTIONS (1 KLIK)
--------------------------------------------------------------------------------
Salin perintah 1-Klik di halaman utama aplikasi web, tempel di Termux:
  cd ~/PaperDollTouch
  unzip -o ~/PaperDollTouch_Source.zip
  git add -A
  git commit -m "Upgrade v2.0.0 Minecraft Mobile Cursor Windows-Style GUI System"
  git push origin main

Tunggu 1-2 menit hingga workflow "Build PaperDollTouch" di GitHub Actions hijau,
lalu unduh artifact "PaperDollTouch" yang berisi:
- PaperDollTouch.levipack
- libPaperDollTouch.so
